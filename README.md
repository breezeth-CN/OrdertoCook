## 模组概览

- **模组名称**：Order To Cook（下单了）
- **核心玩法**：设定菜单 → 接取外卖/堂食订单 → 制作食物 → 打包交付 → 赚取奖励
- **特色机制**：餐厅等级、加急订单、超远距离配送、小费系统、彩蛋顾客、小电驴、餐盘系统、餐厅排行、细致动画、高级厨电
- **货币自定义**：默认货币为 **oTc币**，可在配置文件中自定义奖励货币
- **前置模组**：**Geckolib**
- **兼容版本**：Forge 1.20.1、Fabric 1.20.1、Fabric 1.21.1、NeoForge 1.21.1
- **联动说明**：
  - 联动车万女仆模组可将顾客更换为女仆，需在配置文件中开启
  - 支持将货币设置为 SDM 数字货币，需在配置文件中开启
  - NeoForge 适配航空学模组，需额外安装 [**下单了:兼容**](https://modrinth.com/mod/ordertocookcompat)
- **推荐安装**：[**消费了**](https://modrinth.com/mod/coin-to-shop) — 用于设置商店，消耗你赚取的 oTc 币！

## 基础玩法

### 核心设备

| 设备 | 说明 |
|------|------|
| **打单机** | 放置在世界中，点击打开界面等待订单刷新 |
| **椅子** | 配合堂食顾客使用 |
| **操作台** | 装盘和打包食物的核心工作区 |
| **立牌** | 用于设置店铺菜单 |
| **包装架** | 用皮革右键补充，以填充包装袋 |
| **餐盘架** | 用空餐盘右键补充，以填充餐盘 |
| **洗碗池** | 放入脏餐盘，空手长按右键刷盘子 |

### 菜单系统（全新机制）

- 移除了原版的黑/白名单模式
- 新增「**立牌**」方块：放置后可在其中配置你的店铺菜单
- **智能菜单识别**：订单食物**只会**从立牌设置的菜单中生成
- **设置高级食物**：同等级下的高饱食度食物会有额外奖励

### 订单系统

多种订单类型：不同等级订单、加急订单、超远距离配送订单、自动到店顾客（黄色边框，右键获取订单）。

自由选择：按需接单，在操作台制作食物后打包/装盘交付。

### 等级系统

- **等级上限提升**：餐厅等级从原先扩展至 **8级**
- **更多增益**：每升一级都能获得更丰厚的奖励加成
- **饱食度影响**：打单机升级会受到**立牌设置的菜单总饱食度**影响——鼓励你提供更丰富、更高级的菜品

## 1.3 版本新增内容

### 细致动画

持续更新制作了玩家、顾客以及方块动画，包括：
- 玩家坐在椅子上的待机动画
- 椅子上按鼠标左键的喝彩动画
- 洗碗动画
- 电瓶车骑行动画
- 方块动画：打单机新订单、冰箱、洗碗机、炉灶等
- 顾客的 4 种待机动画、出现和消失动画等

### 小电驴

送外卖怎么能缺少它！
- 左键按喇叭、右键开车灯
- 使用红色、蓝色、黄色、白色染料可染色
- 上车自动佩戴安全帽
- Shift+右键或在骑行时按 **E** 键打开保温箱，存入保温箱的包裹会在提示栏中带有箭头指示，支持多个外卖包裹

### 餐厅排行

- 在打单机中进入排行榜，查看服务器各餐厅的经营情况
- 金牌餐厅（默认按总收益排序）获得隐藏成就

### 餐盘系统

**新增方块**：
- **餐盘货架**：在操作台中使用"装盘"功能，为堂食顾客提供可重复利用的餐盘盛放食物，不再消耗皮革打包。装盘会提供多种随机食物模型。
- **洗碗池**：食物被顾客食用后会在桌上留下脏盘，放入洗碗池中空手右键开始刷盘子。

**使用餐盘效果**：
- 顾客会有进食动画
- 有概率触发"好吃到爆炸"效果
- 未来将有助于提升餐厅评价和收益

### 高级家电（1.3.5 新增）

使用 **oTc 工具箱** 升级高级家电方块：

| 设备 | 说明 | 升级自 |
|------|------|--------|
| **冰箱** | 双开门 2 格高，食材堆叠上限 128，允许打包台消耗冰箱食材 | 两格高木桶 |
| **洗碗机** | 全自动洗碗 | 洗碗池 |
| **炉灶** | 一次烧制 3 种食物，兼容农夫乐事 / Let's do / 森罗厨房 | 烟熏炉 |

## 项目结构

```
├── common/                  # 跨版本通用代码
├── fabric-1.20.1/           # Fabric 1.20.1 平台
├── fabric-1.21.1/           # Fabric 1.21.1 平台
├── gradle/                  # Gradle wrapper
└── build.gradle             # 根项目构建脚本
```

## 开发

本项目使用 Gradle 多模块结构，`common` 模块存放共享逻辑，各平台子模块包含平台特定实现。使用 GeckoLib 进行实体动画渲染。
